# Task 5.1: Terminal Navigation Log

## Exercise 1: Basic Navigation

| Command | What it did |
|---|---|
| `pwd` | Displayed my current directory. |
| `ls` | Listed files and folders. |
| `cd ~/Documents` | Navigated to my Documents folder. |
| `cd ..` | Moved one directory backwards. |
| `cd ~` | Returned to my home directory. |
